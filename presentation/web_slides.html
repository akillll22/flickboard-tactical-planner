UJIAN TENGAH SEMESTER (UTS) • PEMROGRAMAN MOBILE

FLICKBOARD

FC Barcelona Tactical Planner & Match Simulation Engine

Aplikasi Mobile & Web Modern Berbasis Flutter, BLoC State Management, Integrasi Live AllSportsAPI, dan Algoritma Simulasi Taktis Hansi Flick.

⚽ Flutter 3 & Dart 3  |  Cross-Platform Android & Web  |  Clean Architecture
Pendahuluan
Latar Belakang & Masalah yang Diselesaikan
1. Tantangan Taktik Modern
  • Filosofi Hansi Flick mengandalkan Garis Pertahanan Sangat Tinggi (High Line) dan Gegenpressing intens.
  • Kompleksitas rotasi posisi fase bertahan (4-2-3-1) vs menyerang (3-2-4-1).
  • Risiko serangan balik cepat lawan jika offside trap gagal.
2. Batasan Aplikasi Konvensional
  • Mayoritas papan taktik mobile hanya kanvas gambar diam tanpa data pemain asli.
  • Tidak terhubung dengan jadwal kompetisi riil (La Liga & Champions League).
  • Tidak ada mesin simulasi otomatis untuk menguji keputusan taktis.
3. Solusi yang Dihadirkan
  • Papan taktik Drag-and-Drop interaktif untuk Mobile & Web.
  • Sinkronisasi skuad resmi 35 pemain dan jadwal laga terkini via AllSportsAPI.
  • Mesin simulasi cerdas penghitung xG, penguasaan bola, & evaluasi Grade taktik.
Arsitektur Sistem
Tech Stack & Pola Desain (Clean Architecture)
Frontend & Framework
  • Flutter 3 & Dart 3: Single codebase untuk Web Chrome & Android APK.
  • Custom UI/UX: Barca Dark Theme, Glassmorphism, & pitch markings presisi.
  • Dukungan Mouse Pointer (Web) & Haptic Touch Long-Press (Android).
State Management (BLoC / Cubit)
  • flutter_bloc ^8.1: Memisahkan UI sepenuhnya dari logika bisnis aplikasi.
  • TacticalBoardCubit: Mengelola Starting XI, bangku cadangan, & swap formasi.
  • SimulationCubit: Mengontrol komputasi probabilitas laga & emit status live.
Data Layer & REST API
  • TacticalRepository: Mengelola koneksi HTTP jaringan asinkron.
  • AllSportsAPI: Endpoint resmi tim ID 97 dan Fixtures La Liga & UCL.
  • Data Models: PlayerModel, MatchModel, OpponentModel, SimulationResultModel.
In-Memory Caching (Anti Limit)
  • Mekanisme TTL Caching 6 Jam: Menghemat kuota API agar tidak terkena limit.
  • Zero-Downtime Fallback: Jika offline, otomatis memakai 35 data skuad lokal terverifikasi.
  • Algoritma sanitasi ID unik: Bebas duplikasi starting XI.
Fitur Unggulan 1
Papan Taktik Interaktif & Drag-and-Drop Lintas Platform
Mekanisme Papan Taktik (Tactical Pitch)
  • Lapangan Vertikal CustomPainter: Kotak penalti, titik penalti, dan garis tengah presisi.
  • 11 Slot Starting XI Proporsional: Posisi akurat (GK, LB, LCB, RCB, RB, LDM, RDM, LW, AM, RW, CF).
  • Transisi Formasi Instan: Sakelar formasi antara 4-2-3-1 dan 3-2-4-1 (In-Possession Hansi Flick).
  • Visual Pin Informatif: Nomor punggung, nama pemain ringkas, dan gradien Blaugrana.
Dukungan Drag & Drop Web & Mobile
  • Deteksi Platform Cerdas (kIsWeb): Draggable instan di Web, LongPressDraggable dengan haptic feedback di Mobile.
  • Fitur SWAP Instan: Menukar dua pemain yang sama-sama di lapangan langsung bertukar posisi secara mulus.
  • Substitusi Bangku Cadangan: Menarik pemain dari bench otomatis menggantikan pemain di lapangan.
  • Modal Bottom Sheet: Opsi alternatif pemilihan pemain via tap sentuhan cepat.
Fitur Unggulan 2
Integrasi Live AllSportsAPI & Smart Caching
Konektivitas Live AllSportsAPI
  • Endpoint Tim FC Barcelona (ID: 97): 35 pemain terverifikasi lengkap dengan nomor & posisi.
  • Jadwal Laga Musim Ini: La Liga EA Sports & UEFA Champions League.
  • Lawan Riil: Villarreal CF, Sabah FC, Deportivo, Atlético Madrid, hingga Manchester City.
  • Profil Lawan Dinamis: Nilai serang, nilai bertahan, pressing vulnerability, & key player.
Arsitektur Smart Caching (Anti Limit)
  • Tantangan: API publik memiliki batas kuota permintaan harian (rate limit).
  • Solusi TTL Cache: Data disimpan di memori selama 6 jam. Navigasi & simulasi memakai cache (0 kuota terbuang).
  • Refresh Manual: Pengguna tetap dapat memperbarui data via tombol refresh di AppBar.
  • Kecepatan Instan: Halaman dimuat dalam milidetik tanpa jeda berulang.
Fitur Unggulan 3
Mesin Simulasi Taktis & Evaluasi Hansi Flick
Tiga Parameter Taktis Utama
  • PPDA (Passes Per Defensive Action): Mengukur intensitas Gegenpressing merebut bola kembali.
  • Ketinggian Garis Pertahanan (1 - 10): Mengontrol agresivitas jebakan offside (Offside Trap).
  • Tempo Build-Up Serangan (1 - 10): Mengatur kecepatan sirkulasi bola dari lini tengah ke sayap.
Output & Laporan Analisis Taktis
  • Probabilitas Hasil Laga: Persentase Win / Draw / Loss dihitung dinamis.
  • Proyeksi Statistik: Penguasaan Bola (%), xG Barcelona, xG Lawan, & Jumlah Jebakan Offside.
  • Evaluasi Grade Hansi Flick (A+, A, B, C): Menilai efektivitas strategi pengguna.
  • Peringatan Risiko Otomatis: Peringatan jika garis terlalu tinggi tanpa intensitas pressing cukup.

Evaluasi Teknis
Tantangan Pengembangan & Solusi yang Diterapkan
1. Responsivitas Layar
  • Tantangan: Layar desktop Chrome lebar membuat lapangan membesar berlebihan dan tombol menutupi isi layar.
  • Solusi: Menerapkan ConstrainedBox(maxWidth: 500) dan bottomNavigationBar resmi.
2. Drag-and-Drop Hybrid
  • Tantangan: Gesture di web dan mobile memiliki kebiasaan interaksi berbeda.
  • Solusi: kIsWeb Draggable instan di Web, LongPressDraggable dengan delay 180ms di Android.
3. Batas Kuota API
  • Tantangan: Navigasi bolak-balik berisiko menghabiskan limit API eksternal.
  • Solusi: Smart In-Memory Caching 6 jam dan repository fallback offline 35 pemain.
